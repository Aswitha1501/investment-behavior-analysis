# Investment Behavior Analysis Dashboard

Power BI dashboard analyzing investment behavior patterns across age, gender, savings objectives, and preferred investment instruments.

![Dashboard](Screenshot%202026-09-11%20171827.png)

## Tools Used
- Power BI

## Dataset
Survey data on investment behavior (40 respondents).

## Dashboard Includes
- KPI cards: Average Age, % Who Invest, Respondents
- Gender slicer to filter the whole dashboard
- Investment preference by gender
- Preference by savings objective
- Investment duration
- Top reasons for choosing equity
- Where respondents get investment information

## Key Insights
- 93% of respondents already invest, with an average age of 27.8
- Government Bonds have the highest average preference score for both genders
- Capital Appreciation is the top reason for choosing equity
- Financial Consultants are the top source of investment information (40%)
